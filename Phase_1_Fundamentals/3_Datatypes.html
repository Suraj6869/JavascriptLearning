Primitive Data Types

primitive datatype - stack memory allocation 1. String (" "): Represents a sequence of characters. Example: "Hello, World!" 2. Number (34): Represents both integer and floating-point numbers. Example: 42, 3 3. Boolean (true/false): Represents a logical entity that can have two values: true or false. Example: true, false 4. Null (null): Represents the intentional absence of any object value. Example: null 5. Undefined (undefined): Represents a variable that has been declared but has not been assigned a value. Example: undefined 6. Symbol (Symbol('description')): Represents a unique identifier. Example: Symbol('description') reference datatype - heap memory allocation 1. array ([]): Represents an ordered collection of values. Example: [1, 2, 3], ["apple", "banana", "cherry"] 2. object literals ({ }): Represents a collection of key-value pairs. Example: { name: "John", age: 30 } 3. function (function): Represents a reusable block of code that performs a specific task. Example: function 4. date (new Date()): Represents a specific point in time. Example: new Date()
