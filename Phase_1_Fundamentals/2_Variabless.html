Variables

Most Common programming case types:

  1. camelCase: Used for variables and functions. The first word is lowercase, and subsequent words are capitalized. Example: myVariableName, calculateTotal().
  2. kebab-case: Used for file names and URLs. Words are separated by hyphens. Example: my-variable-name, calculate-total().
  3. pascalCase: Used for class names and constructors. Each word is capitalized. Example: MyClassName, CalculateTotal().
  4. snake_case: Used for constants and sometimes for variable names. Words are separated by underscores. Example: MY_CONSTANT_VALUE, my_variable_name.
